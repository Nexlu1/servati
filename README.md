# SERVATI

## The Worlds That Held the Dead

Created by Marcus Frost.

Servati is a speculative evolution and future-history project exploring memory, continuity, obligation, and the long aftermath of humanity.

The project follows the Continuance, a system originally created to preserve the dead, and the civilizations, ecologies, and post-human descendants that emerge around it over immense spans of time.

## Current Release

**Version 11 — Differentiation and Deep-Time Expansion Edition** is the current
released canon.

Version 12 is in development. All new V12 lore in this repository is explicitly
labelled **DRAFT** and has no authority over Version 11 unless it passes the
documented review and promotion process.

The source-controlled [authoritative Version 11
manuscript](SERVATI_V11_AUTHORITATIVE_MANUSCRIPT.md) is the released canon.
Structured indexes and V12 foundations cite it directly; verification of a V11
basis does not promote any new V12 name, event, culture, or particular.

# DRAFT Source Review — Candidate Version 11 Terms

- **Canon status:** DRAFT
- **Source verification:** SOURCE-UNAVAILABLE

These definitions are assertions from the reviewed V12 working pack. They are
preserved so they can be compared with the Version 11 manuscript later. This
file is not a canon glossary.

- **SERVATI** — the pack describes the title as meaning the kept, preserved,
  or guarded rather than salvation.
- **Continuance** — the pack describes an original system created when ordinary
  institutions could no longer keep bodies, names, records, and claims together
  under mass overload.
- **burden** — the pack describes a preserved body, remnant, or matter-state
  held together with its obligation or identity context.
- **custody** — the pack describes holding without falsely resolving, erasing,
  consuming, misnaming, or abandoning.
- **Reliquary Earth** — the pack describes Earth as an active preservation
  ecology.
- **Scattered Lamp** — the pack describes an isolated continuity centre that
  preserves only part of the inheritance.
- **Remains / Memory / Seed / Ritual / Structure / Pattern** — the pack
  describes six dominant inheritance logics.
- **Archive Faith** — the pack describes a sacred identity system built around
  a dominant preservation logic.
- **Custody War** — the pack describes conflict over rightful preservation,
  access, relocation, or interpretation.
- **Great Misreading** — the pack describes an era or condition in which
  humanity survives as evidence but not as a whole understanding.
- **Choir** — the pack describes a large custodial civilisation formed by
  coordinated continuity centres around a shared preservation logic.
- **Shrine World** — the pack describes a planet or major body reorganised
  around preservation.
- **Outer Custody** — the pack describes a remote cold reserve withdrawn from
  active worlds.
- **Luminous Remnant** — the pack describes witness preserved through emission,
  signal, swarm, or light-field after local structures fail.
- **Black Shrine** — the pack describes a withheld custody structure protecting
  irreducible or dangerous unresolved remnants from false resolution.
- **Great Thinning** — the pack describes the loss of mutual answer among
  routes, systems, and worlds.
- **Last Maintenance** — the pack describes care narrowed to a final local act.
- **Last Census** — the pack describes a final accounting with several named
  categories of custody and loss.

The pack cites a Version 11 appendix for these terms. That citation must be
checked directly before any item moves out of this research quarantine.
